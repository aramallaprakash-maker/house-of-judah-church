# House of Judah Church

Mobile-friendly installable church PWA for Pastor Judah Suzan.

## Publish
Enable GitHub Pages from main branch, root folder, in repository Settings → Pages. Open the published HTTPS URL and use Add to Home Screen / Install App.

## Pastor controls
Edit `content.json` to publish announcements. Only trusted GitHub collaborators should have write access. No public admin login is implemented yet.

## Features
Live worship and sermon links, external Bible reading, prayer-message preparation (no submission or storage), announcements, church directions, song link, service information, and installability. English, Telugu, Hindi plus partial Spanish, French, Portuguese and Arabic. Not yet translated into every language.
